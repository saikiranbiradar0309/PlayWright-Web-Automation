# What is Playwright?

**Playwright** is an open-source **end-to-end test automation framework** developed by Microsoft.

It is mainly used to automate and test **web applications**.

Playwright allows us to automate browsers such as:

- Chromium
- Google Chrome
- Microsoft Edge
- Firefox
- WebKit (Safari browser engine)

---

# Why Do We Use Playwright?

Playwright is used to automate the actions that a real user performs on a web application.
